y no hace falta para aprobar. Está acá porque son cosas que te vas a cruzar
trabajando y conviene que las hayas visto una vez.

Cada anexo arranca desde el stack del curso: si ya tenés `stack/` levantado, lo
podés probar en diez minutos.
